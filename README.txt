VYAPAR AR (ARI-OS) - AR INDUSTRIES MANUFACTURING ERP
Open index.html in a modern browser.

Included:
- Vyapar AR (ARI-OS) Branding & Light Theme UI
- GST Tax Invoice Generator with live carton pack stock conversion
- Automated Wholesale & Retail pricing lookup engine
- Modular Box & Fan Box inventory telemetry
- Attendance & workforce technician rosters
- REST API Client connecting to Spring Boot (port :8080) & MySQL

Folder Structure:
- frontend/ : Single-page application UI (HTML, CSS, JS)
- backend/  : Java Spring Boot REST API (Port 8080, MySQL)
